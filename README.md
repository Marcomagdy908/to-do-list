# ✅ Task Manager

**React · JavaScript · Vite**

A browser-based task manager for creating, organizing, and editing everyday tasks.

## ✨ Feature reel

- Create and edit tasks through dedicated routes.
- Task filtering and priorities.
- Local storage persistence between browser sessions.
- Light and dark themes with a saved preference.
- AOS animations and responsive styling.

## 🚀 Getting started

Use Node.js 22.12 or later and npm.

```bash
git clone https://github.com/Marcomagdy908/to-do-list.git
cd to-do-list
npm install
npm run dev
```

Open the local URL printed by Vite. To create and inspect a production build:

```bash
npm run build
npm run preview
```

## 🗂️ Project map

| Path | Purpose |
| --- | --- |
| `src/App.jsx` | Routes and theme state |
| `src/newtask.jsx` | New task form |
| `src/edittask.jsx` | Task editing |
| `src/hometasks.jsx` | Task views and filtering |
| `src/settings.jsx` | Theme settings |

## 🧪 Checks

```bash
npm run lint
npm run build
```

Tasks are stored in this browser's local storage. They are not synchronized to an account or another device.
